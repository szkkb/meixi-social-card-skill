## 三、跨字体的三条关键法律结论（对本工具最重要）

1. **OFL 1.1 不要求在成品上署名。** OFL 原文明确：许可对字体「文档/成品」不具传染性（"The requirement for fonts to remain under this license does not apply to any document created using the fonts"）。**但 §2 要求：再分发字体软件副本时，每份副本须包含版权声明与许可全文**。→ 用于社交卡片出图**无需署名**；但若把 `.woff2`/`.ttf` **下发给客户端或内嵌进 App**，必须随附 `OFL.txt` 与版权行。
2. **「免费商用」≠「可内嵌分发」。** 中文字库的「作者声明」型授权普遍允许**使用字体出图**，却常同时禁止「单独出售字体文件」「修改/制作衍生版」「用于嵌入式用途」。设计工具若内嵌/分发字体文件，**属于限制条款的核心命中区**，需逐一取得内嵌授权，或改为**服务端渲染、只下发图片、不下发字体文件**。
3. **商标风险独立于版权。** 多款字体（阿里妈妈、程荣光刻楷、斗鱼追光体、白路棒棒体等）明文禁止将字形用于商标注册；站酷系的「ZCOOL/站酷」本身是注册商标，Google 维护者亦提示显著展示其商标需另行协议。→ 工具内**字体名称的展示方式**与**生成内容用于商标**两条都要单独评估。
