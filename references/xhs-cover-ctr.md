# 小红书封面 CTR 实战专规（图文封面 & 视频封面通用）

> **最高北极星**：在小红书发现页双列信息流中，**封面只为一个指标服务——点击率（CTR）**。
> 封面负责在 0.5 秒内把手指拦下来并制造「必须点开」的缺口；收藏、信任、品牌记忆与私域转化交给**内页（图 2–N）**或**视频正片**。
> **封面与内页是两套相反的规则，绝不可混用。**

---

## 一、 封面 vs 内页：核心规则彻底解耦

| 维度 | 封面（图 1 / 视频独立封面） | 内页（图 2–N / 末页收藏卡） |
|---|---|---|
| **唯一目标** | **首页点击率（CTR）**：0.5 秒拦手 + 诱发点击 | **完读率 / 收藏率 / 信任转化** |
| **信息原则** | **只开环、不闭环（反剧透）**：抛冲突、痛点、悬念、数字反差 | **给足干货与闭环答案**：步骤、公式、对照表、核对清单 |
| **元素上限** | **≤ 3 个视觉单元**（1 主体 + 1 核心大字钩子 + ≤1 极短靶子/悬念签） | 可结构化展开（对比行、提单参数、红圈批注、4–5 条清单） |
| **品牌露出** | **严禁左上角大块企业名/蓝 V 硬广标**（用配色、实拍质感、真人脸做识别） | 抬头、页脚、末页清晰落品牌名（如 `杨美西转运`）承接信任 |
| **字重与对比** | **高冲击优先**：允许超粗黑 `900` / 榜书 + **核心 2–4 字撞色放大（明黄/警示红）** | 保持系统克制美学与长阅读舒适度 |
| **画布密度** | **豁免 4 横带 ≥75% 填充**，允许大面积干净主体/呼吸区突出唯一焦点 | 遵守 4 横带密度检查，避免底部大面积无理由留白 |

## 二、 首页高 CTR 六大硬定律

### 1. 0.5 秒扫视法则（180pt 真实双列验收）
- 小红书发现页双列单卡在手机屏幕上的真实渲染宽度只有 **175–185pt**（不是 360px 整屏宽）。
- 验收必须用 `scripts/build-feed-preview.mjs` 生成的 **180px 真实双列信息流模拟台**（叠加隔壁竞品卡片 + 右上角视频播放标 + 底部外显标题），并用内置 **0.6 秒闪看测试（Glance Test）**检查：0.6 秒内看不清主角或读不完主标题，立刻重写或重排。

### 2. 三元素天花板（3-Element Rule）
单张封面最多只允许出现 **3 个视觉焦点**：
1. **一个强故事/情绪/反差主体**（真人近景情绪、前后对比实物、电子秤/账单特写、真实打包现场）；
2. **一句 6–10 字的强钩子主标题**（带 2–4 字核心关键词撞色/放大）；
3. **最多一个辅助锚点**（极短人群靶子签 ≤6 字，或手绘红圈，或单行悬念签）。

**硬禁令**：
- 严禁在封面上放 **3 栏答案回执 / 01-02-03 完整步骤列表 / 密集参数表格**；
- 封面可见总字数建议 **≤ 20 字**，超过 **26 字**校验器报 WARN，超过 **45 字**直接 FAIL。

### 3. 反剧透铁律（Curiosity Gap）
用户一旦在封面上看完结论，大脑瞬间完成「我已经知道了」的认知闭环，直接划走。
- ❌ **剧透死法**：封面大字「大件运洛杉矶怎么最省钱」+ 底部三栏直接写完「01 自提 / 02 卡派 / 03 拼邮」。
- ✅ **高 CTR 留钩子**：封面大字「运大件去 LA / **别先问单价！**」+ 底部单行悬念「选错拿货方式多花冤枉钱 →」，把 3 种拿货顺序放进**图 2（`X02`）**。

### 4. 双轨不重复：封面字 + 外显标题协同交付
发现页一张卡片 = **封面图** + **下方 1–2 行外显笔记标题（15–20 字）**。
**每次做小红书图文或视频封面，必须同步交付「封面钩子」与「外显标题」，且两者字面重合率必须 < 35%（推荐 < 25%）：**
- **封面字（情绪/冲突/反差/视觉钩子，6–10 字）**：负责把手指停下来。
- **外显标题（人群场景/搜索关键词/具体利益，15–20 字）**：负责承接好奇并完成临门一脚点击，同时吃搜索 SEO 流量。

示例对照：

| 封面主钩子（短狠冲突） | 配套外显标题（场景 + 关键词 + 利益） | 协同逻辑 |
|---|---|---|
| `运大件去LA` / **`别先问单价！`** | `洛杉矶海运家具家电实操：3种拿货顺序搞懂立省末端派送费` | 封面打破直觉制造问号，标题补充「家具家电/洛杉矶海运」搜索词与干货预期 |
| `同样100kg` / **`运费差一半？`** | `国内集运到美国避坑：拆盒减重实测，别再傻傻按原箱体积付泡重` | 封面用数字反差抓眼，标题给出「拆盒减重/体积泡重」核心词 |
| `这些东西寄美国` / **`直接扣仓！`** | `2026留学生敏感货集运清单：零食药品带电哪些能走、哪些千万别塞` | 封面用损失厌恶触发焦虑，标题锚定「2026/留学生/敏感货/零食药品」精准人群 |

在 HTML 封面 `<section>` 上写入 `data-feed-title="配套外显标题"`，校验脚本 `validate-social-deck.mjs` 的 **R15** 会自动检查重复率，且信息流模拟台会自动将其渲染在卡片底部供实测。

### 5. 反广告感 & 活人感优先
- **封面禁止出现企业名大框**：取消左上角白底黑字 `■ 杨美西转运 国内仓 → 洛杉矶` 这类强企业名硬标，取消胶带边缘重复印企业名的强水印感。左上角若需锚定人群，只放 **≤ 6 字的纯用户视角靶子签**（如 `洛杉矶大件海运`、`北美留学生必看`、`实测避坑`）。
- **底图选片 CTR 门槛（与 Kinfolk 氛围选片区分）**：
  - ✅ **优先用**：真人近景/半身情绪抓拍（惊讶、无奈、笃定、手指物证）、仓库真实装卸动作、明显的前后对比双图、高辨识度物证特写（秤上重量数字、打码账单、木架加固 vs 纸箱压瘪）。
  - ❌ **直接拒用或重拍**：画面中央被原厂杂乱印刷大字占满的静止空纸箱（如正中巨大「轻拿轻放 请勿放倒」抢走全部视线）、昏暗模糊远景、淘宝白底商品图、AI 假人/假仓库。

### 6. 小红书双安全区与平台 UI 禁区（`1080×1440`）
小红书在**发现页（3:4）**与**个人主页/分享卡（部分 1:1 裁切）**存在不同的裁切与 UI 叠加：
- **右上角 UI 禁区（重灾区）**：`x: 850–1080px, y: 0–210px`（右侧 `230px` × 顶部 `210px`）。发现页视频卡片在此处固定叠加圆形播放标，图文卡片叠加多图/实况标。**严禁任何主标题文字、数字、人眼或核心红圈落入此区**（校验器 **R13** 自动拦截）。
- **底部边缘缓冲**：`y: 1320–1440px`（底部 `120px`）不放关键小字，避免与发现页圆角及紧贴下方的外显标题视觉打架。
- **个人主页 1:1 中心安全框**：`y: 180–1260px`（左右留白 `≥ 64px`）。核心人像面部与核心爆点大字尽量落在此范围内，保证发现页 3:4 与主页 1:1 都不裁切核心信息。

## 三、 高 CTR 封面钩子公式库（6 大实战模型）

写封面主标题前，先从以下 6 类挑最贴合本篇证据的一类，**不要写百度百科式平淡陈述句**：

1. **损失厌恶 / 反常识警示（避坑类最高 CTR）**
   - 结构：`[动作/场景]` + **`别再…… / 错在这步 / 亏大钱`**
   - 例：`寄大件去美国` / **`别先问单价！`**、`合箱少看一眼` / **`多付三成泡重`**
2. **量化反差 / 极端数字（省钱/实测类主力）**
   - 结构：`同样 [条件]` + **`为什么省一半 / 差出 $400？`**
   - 例：`同样 100kg` / **`运费差一半？`**、`拆掉 12 个鞋盒` / **`立省 6 公斤`**
3. **人群精准点名（蓝 V 垂直获客必备）**
   - 结构：`[精准身份]` + **`寄前必看 / 别踩这3坑`**
   - 例：`洛杉矶搬家党` / **`家具海运避坑`**、`留学生寄零食` / **`哪些直接扣？`**
4. **前后对比冲击（配合 `C02` 双图分屏）**
   - 结构：画面左右/上下直接呈现实拍反差 + 顶部短钩子
   - 例：左「原箱塞满空气」vs 右「拆盒抽真空少一半体积」+ **`体积重怎么省`**
5. **物证悬念红圈（配合 `C04` 特写红圈）**
   - 结构：圈出真实秤数 / 账单 / 违禁细节 + 抛出未闭合疑问
   - 例：红圈指着箱角/单据 + **`就因为少贴这个，整箱卡海关？`**
6. **高价值清单「半露」诱饵（配合 `C05` 收藏向封面）**
   - 结构：明确给出稀缺清单名 + 画面露出前 2 条真货 + 底部提示剩余在后页
   - 例：`2026 敏感货` / **`能寄清单（附实测）`** + 露出 2 行 + `完整 15 类对照在图 2 →`

## 四、 五大高 CTR 封面原型（按选题轮换，打破模板疲劳）

不要每篇笔记都套同一个封面模具。在统一视觉基因（品牌蓝 `#0060C9` + 真实仓储/人物质感 + 高对比亮黄 `#FFE14D` / 记号红 `#D0433B`）下，按选题轮换以下 5 种原型（全部内置在 `assets/template-xhs-card.html`）：

| 原型 ID | 名称 | 最佳适用场景 | 适用形态 | 核心视觉机制 |
|---|---|---|---|---|
| **`X01`** | **真仓悬念大片** | 常规攻略、省钱选型、封箱实拍（默认图文封面） | 图文 / 视频 | 满版真仓实拍 + 去广告标短靶子签 + 避右上角品牌蓝撕口胶带（含亮黄爆点词）+ 单行底部悬念签（**严禁 3 栏剧透答案**） |
| **`C02`** | **双图强对比** | 拆盒减重、打木架 vs 裸寄、国内堆山 vs 海外拆箱、渠道费用对比 | 图文 / 视频 | 左右或上下双实拍拼图 + 红/蓝高对比角标（`❌ 原箱/踩坑` vs `✓ 实测/省钱`）+ 跨缝巨型反差标题 |
| **`C03`** | **真人情绪口播** | **视频封面主力**、老板/仓管真人出镜避坑、行业真话吐槽 | **视频首选** / 图文 | 近景/半身真人情绪帧（可选 `lift-subject.swift` 抠图白边/前景压字）+ 底部暗色柔梯 + `Noto Sans SC 900` 超粗双层亮黄撞色大字 |
| **`C04`** | **物证红圈悬念** | 电子秤公斤数、运费单据局部、包装隐患、禁限品拆检 | 图文 / 视频 | 高清物证特写 + 双层白底手绘红圈 `.ring` 精准套住悬念点 + 避让区强痛点钩子 |
| **`C05`** | **半露清单诱饵** | 敏感货通关表、美国各州时效对照、寄前自查表（高收藏选题） | 图文首选 | 顶部蓝胶带/强标题头 + 下半倾斜齿孔面单**只露前 2–3 条** + 底部纸面渐隐与「图 2 看全表 →」钩子 |

## 五、 小红书视频封面专项工作流（9:16 视频 → 3:4 高点击封面）

发小红书竖屏视频（9:16）时，**绝对不要用系统随机首帧，也不要直接把 9:16 封面硬塞进发现页**。走以下 5 步标准流：

1. **低成本选高情绪帧**：用仓库自带脚本从原始视频抽稀疏联系表，挑出**情绪张力最高 / 手势动作最清晰 / 货箱反差最强**的候选帧（严禁闭眼、说话嘴歪、全黑片头、呆板证件照表情）：
   ```bash
   python3 scripts/make-video-contact-sheet.py source.mp4 assets/video-frames.jpg --frames 12 --cols 4
   ```
   用 Read 工具看联系表，锁定时间戳后导出高清静态帧：
   ```bash
   ffmpeg -y -ss <秒数> -i source.mp4 -frames:v 1 -q:v 2 assets/video-cover-frame.jpg
   ```
2. **景别裁剪与主体聚焦**：
   - 把 9:16 帧裁入 `1080×1440`（3:4）容器时，真人口播优先放大到**胸部以上近景 / 半身**，让脸部表情在 180pt 缩略图下依然清晰可读（人眼落在画布上 `28%–45%` 高度区）；
   - 必要时用本地 Vision 脚本一键抠出前景人物/核心货物，叠出前景压字或模切白边层次：
     ```bash
     swift scripts/lift-subject.swift assets/video-cover-frame.jpg assets/person-cutout.png
     ```
3. **选用视频主力原型**：口播解说默认走 **`C03` 真人情绪口播**；实拍打包对比走 **`C02`**；实拍物证曝光走 **`C04`**；仓库现场动作走 **`X01`**。
4. **标记视频面并死守右上角**：在封面 `<section>` 加上 `data-role="cover" data-surface="video"`。标题、关键词、人物核心脸部全部避开右上角 `230×210px` 播放标禁区（校验器 **R13** 对 `data-surface="video"` 启用 FAIL 级拦截）。
5. **180px 视频模式验图**：跑 `node scripts/build-feed-preview.mjs <task-dir>`，打开预览页切到「视频模式 + 安全框透视」，确认播放标不挡字、1:1 框不切脸、0.6 秒闪看能秒懂。

## 六、 一题多封（A/B 封面 PK）默认交付规范

小红书创作服务平台已原生支持**封面测试 / 封面 PK**（上传多张候选封面由系统小流量切流实测 CTR，自动锁定胜出封面）。利用 AI 极低的边际出图成本：

- **默认策略**：只要用户做小红书图文封面或视频封面（除非明确只要 1 张），在 `index.html` 中为同一选题并行生成 **2–3 版高差异候选封面**（例如：**方案 A `X01` 悬念大片 / 方案 B `C03` 真人情绪 / 方案 C `C02` 对比实证**，或同一底图配 2–3 组不同痛点钩子），每版绑定各自互补的 `data-feed-title`。
- **验图交付**：使用 `node scripts/build-feed-preview.mjs <task-dir>` 把这 2–3 版候选封面直接放进 **180px 真实双列竞品模拟流**中横向 PK——用户要么 3 秒肉眼定稿，要么直接把 2–3 张图上传小红书官方「封面测试」让真实流量投票。

## 七、 通用模式（Editorial / Swiss）做小红书封面时的 CTR 例外条款

当用户用通用模式（`template-editorial-card.html` / `template-swiss-card.html`）制作**以高点击率为首要目标的小红书封面**时，可在封面 `<section>` 上添加 `data-role="cover" data-ctr-mode="true"`，触发以下三项授权例外（内页保持原体系不变）：
1. **字重解禁**：Swiss 封面主标题不再被 R3 限制在 `weight <= 300`，允许使用 `700–900` 粗体 + 关键词高饱和撞色；Editorial 封面允许 `700` 粗衬线/花体字与高对比纯白/亮黄。
2. **密度解禁**：封面豁免 R5 的 4 横带 ≥75% 填充要求，优先保住单一视觉焦点与呼吸留白。
3. **双轨与禁区生效**：同样接受 R13（右上角播放标禁区）、R14（封面字数过载）、R15（与外显标题重复率）的 CTR 护栏检验。
